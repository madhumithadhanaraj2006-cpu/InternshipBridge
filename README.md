# InternshipBridge

## Internship Management Platform for Students and Administrators

InternshipBridge is a web-based internship management platform designed to help students explore internship opportunities, submit applications, and track application status.

It also provides an administrator interface to review and manage student internship applications.

## 🎯 Objectives

- Help students find internship opportunities
- Allow students to submit internship applications
- Allow students to track application status
- Help administrators review applications
- Maintain student and application information in a structured database

## 🚀 Features

### Student
- Student login
- Student dashboard
- View available internships
- Apply for internships
- View submitted applications
- Track application status

### Administrator
- Admin login
- Admin dashboard
- View student applications
- Review application details
- Manage application status

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- SQLite
- Git & GitHub
